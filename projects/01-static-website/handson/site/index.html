レベル1 静的Webサイト公開環境(S3 + CloudFront + OAC)

このページは Amazon S3 に保存された HTML を、Amazon CloudFront 経由で HTTPS 配信しています。

構成のポイント

  • S3バケットはパブリックアクセスをすべてブロック(非公開のオリジン)
  • CloudFront の OAC(Origin Access Control)経由でのみ S3 から取得
  • HTTP アクセスは HTTPS へ自動リダイレクト
Built with AWS CLI v2 / このページが表示されていれば構築成功です。
