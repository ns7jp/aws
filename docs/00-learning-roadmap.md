# 学習ロードマップ

## この教材で身につける力

目標は AWS サービス名の暗記ではなく、次の問いに理由付きで答えることです。

1. なぜその構成にしたか
2. どの通信が、どこからどこへ、何番ポートで流れるか
3. どこが壊れたら何が起き、どう検知・復旧するか
4. 構築できたと何をもって証明するか

## 最初に覚える10語

| 用語 | 一言で | この案件での役割 |
|---|---|---|
| Region | 地理的なサービス提供地域 | `ap-northeast-1` を既定値にする |
| AZ | 独立したデータセンター群 | 2つ使い、片系障害に備える |
| VPC | 自分専用の仮想ネットワーク | `10.20.0.0/16` |
| Subnet | VPC を用途別に分けた区画 | public と private を各 AZ に作る |
| Route table | 宛先ごとの次の行き先 | public は IGW、private は NAT |
| Security Group | リソース単位の状態保持型FW | ALB と EC2 の通信を最小化する |
| ALB | HTTP/HTTPS の入口・振り分け役 | 正常な EC2 にだけ転送する |
| EC2 | 仮想サーバー | nginx のデモページを実行する |
| Auto Scaling | 台数維持・自動置換 | 2台を2 AZ に分散する |
| CloudWatch | 監視・ログ・通知 | CPU、5xx、正常台数を監視する |

## 3つの暗記ルール

- **置き場所**: 外から直接使う入口は public、サーバーは private。
- **通信許可**: IP アドレス全体ではなく、できるだけ「前段の Security Group」から許可。
- **運用接続**: SSH 22番をインターネットへ開けず、Session Manager を使う。

## 手を動かす演習

### 演習1: パケットの旅を説明する

「利用者がブラウザーでアクセスして nginx の応答を受け取る」までを、次の語をすべて使って説明してください。

`Internet Gateway / ALB / ALB Security Group / Target Group / EC2 Security Group / nginx`

### 演習2: 設計ミスを探す

次の案の問題と修正案を書いてください。

1. EC2 に公開 IPv4 を付け、22番を `0.0.0.0/0` から許可する
2. ALB と EC2 を1つの AZ にだけ配置する
3. アラームの通知先と初動担当を決めない
4. `terraform apply` の結果だけを成功証跡とする

### 演習3: 自己採点

- 初級: 構成図を見て各部品を説明できる
- 中級: 図なしで通信経路と障害時の動作を説明できる
- 実務準備: 要件、設定値、試験項目、証跡を相互に結びつけられる

## 安全上の注意

- 個人の学習用 AWS アカウント以外で実行しない。
- MFA、最小権限、予算通知を先に設定する。
- NAT Gateway、ALB、EC2、CloudWatch Logs などは利用時間・通信量等により料金が発生する。
- `terraform.tfstate` には機密情報が入り得る。Git に追加しない。
- 削除後も Elastic IP、スナップショット、ログ等が残っていないか確認する。
